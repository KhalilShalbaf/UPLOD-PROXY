# URL Upload Proxy

یک ابزار ساده برای آپلود فایل از طریق لینک URL روی سرویس‌های آپلود مختلف.

## نحوه استفاده

1. این ریپازیتوری را فورک کنید یا مستقیماً استفاده کنید
2. به تب **Actions** بروید
3. روی **URL Upload Proxy** کلیک کنید
4. دکمه **Run workflow** را بزنید
5. لینک فایل مورد نظر را وارد کنید
6. ورکفلو فایل را دانلود و روی چندین سرویس آپلود می‌کند
7. لینک‌های دانلود مستقیم در لاگ‌ها نمایش داده می‌شوند

## سرویس‌های پشتیبانی شده

- **tmpfiles.org** - لینک موقت (1 ساعت)
- **pixeldrain** - لینک دائمی
- **uguu.se** - لینک موقت
- **litterbox.catbox.moe** - لینک موقت (1 ساعت)
- **catbox.moe** - لینک دائمی
